# AI 客服结构化记忆

`ai_chat_messages` 保存完整聊天记录，用于页面恢复；新增 `ai_chat_sessions` 每段会话只有一行 `memory_json`，保存短小的购物条件：商品关键词、预算范围、偏好、最近意图和更新时间。

```text
最近原始消息 + 结构化购物记忆 → LangGraph → 回答
                                  ↓
                    复用已有 intent/search_keyword 更新 JSON
```

它不增加 DeepSeek 调用：关键词来自原本的意图识别，预算由确定性正则提取。示例：

```json
{"topic_keywords":["笔记本","轻薄"],"budget_max":5000,"preferences":["轻薄","学生"]}
```

用户之后问“有更便宜的吗？”时，Prompt 会带上该短记忆，不需要把二十轮原始聊天再次发送给模型。
## 切换商品话题

意图识别原本就会调用一次模型；现在同一次调用还会返回 `topic_mode`：`continue` 表示延续当前商品，`new` 表示明确换成另一种商品。`new` 会在写入新关键词前清除旧商品的关键词、预算和偏好，避免“笔记本预算 5000 元”错误影响“拍照手机”。这同样不增加模型调用。
